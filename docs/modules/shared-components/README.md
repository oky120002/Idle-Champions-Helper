# shared-components 文档入口

- `docs/modules/shared-components/shared-components-design.md`：共享组件治理规则、抽取准入条件、开发与测试规范
- `docs/modules/shared-components/component-list.md`：现有可复用组件目录（路径 / 场景 / 能力 / 使用位置）
- `docs/modules/shared-components/helper-list-and-selection.md`：helper 清单、选择建议和不建议抽取的模式
- `docs/modules/shared-components/page-workbench-design.md`：全站页面工作台的结构签名、顶部小导航、左右壳层、滚动动效与页面归位映射

开发前先查 component-list；只有现有资产覆盖不了场景时，再回到 design 判断是否值得新增共享组件。
