# investigations 文档入口

- 作用：收纳排查、验证、环境确认和历史问题记录；只在需要复现或核对证据时进入。

## 主题入口

- `docs/archive/investigations/runtime/README.md`：本地运行、预览、浏览器行为与页面异常

## 读取建议

- 先看 `docs/runbooks/README.md` 是否已有当前操作手册
