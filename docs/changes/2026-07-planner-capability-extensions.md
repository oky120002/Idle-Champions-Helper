# planner 能力扩展

**Status**: Draft
**Type**: change
**Scope**: planner
**Created**: 2026-07-27

## 目标

在稳态、可解释推荐保持可靠的前提下，扩展当前无法精确求值或不在结果合同中的能力。

## 范围

- 数值表达式求值器：统一解析 stack 数量、复合 amount expression 与阵型聚合查询。
- 综合目标：评估伤害、存活、速度、可获得性与解释复杂度的组合评分。
- 逐步模拟：覆盖逐区、击杀、时间窗口、动态叠层和主动技能精确窗口。
- 输出扩展：独立的逐槽位替补与同席位竞争字段。
- 场景扩展：多队伍、Trials、Time Gate、活动与赛季临时加成投影。
- 手动参数：金币预算、装备、专长、传奇与专精覆盖控件。

## Checklist

- [ ] 冻结数值表达式 AST 与求值上下文，先覆盖纯英雄、存档和常量节点。
- [ ] 覆盖阵型聚合与装备效果复合表达式，未知节点继续进入 warning。
- [ ] 为新增推荐目标定义可解释的目标量、排序稳定性和回归样例。
- [ ] 扩展输出合同并补齐同席位竞争与槽位替补测试。
- [ ] 每项落地后同步当前规范并从本 change 删除已完成范围。

## 验收

任何新增能力都必须可解释、可回归验证；无法静态求值的效果不得静默进入目标值。
