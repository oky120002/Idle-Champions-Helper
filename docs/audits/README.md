# audits/ —— 审计报告

按轮次归档的深度审计报告。每份是一次性的结构化排查，含发现、证据和处置结论。结论落地后标注收口状态，报告本身保留作回归基线和决策依据。

## 时点特性

审计是某个时间点的结构化排查结论。随项目推进，审计中的数据、状态和结论会自然过时——这是固有特性，不是缺陷。**不要求审计文档与当前态同步**；查当前态去 `specs/`。报告保留作回归基线，结论落地后标注收口状态，不再持续维护。

## 与其他目录的关系

- 审计**发现**的事实 → `research/`
- 审计引发的**决策** → `decisions/`
- 审计确认的**当前态** → `specs/`
- 审计暴露的**需求** → `requirements/`
- 一次性事故排查（非系统性审计）→ `archives/investigations/`

## 命名

`<topic>-audit.md` 或 `<topic>-recon.md`（侦察，发现少于 2 个真缺口时不展开完整审计）。
