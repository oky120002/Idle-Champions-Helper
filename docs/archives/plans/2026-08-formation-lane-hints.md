# 阵型前中后排提示

**状态**: 已落地
**类型**: change
**范围**: formation 数据管线与编辑器
**创建日期**: 2026-08-19
**目标**：复用官方槽位列号生成稳定的前排 / 中排 / 后排提示，减少用户按坐标理解阵型的成本。

## 规则

- 官方列号越大越靠前，最小列为后排，最大列为前排。
- 两端之间的列为中排；只有一列时归入中排；两列时不生成中排槽位。
- 生成结果只包含现有槽位 id，保持归一化槽位顺序。
