# 包管理器切换到 pnpm

**状态**: 已确认
**类型**: milestone
**范围**: system
**创建日期**: 2026-08-25

## 来源

- 需求库：无
- 其他来源：用户明确要求全面切换到 pnpm，并同步、安装全部工作树

## 目标

统一使用固定版本的 pnpm，降低多工作树重复安装的磁盘与时间成本，并让本地、CI、文档和脚本使用同一包管理器。

## 范围

- `package.json`、锁文件与依赖安装行为
- GitHub Actions、Playwright 启动命令和项目脚本
- README、AGENTS、当前 runbook/spec 文档中的包管理器命令
- 所有干净 linked worktree 的分支同步与依赖重装

## 阶段 Checklist

- [x] 阶段 1: 盘点包管理器入口、工作树状态和远端分支 —— 验证方式：逐工作树状态与远端 ref 核验
- [x] 阶段 2: 完成 pnpm 锁文件、CI、脚本和当前文档迁移 —— 验证方式：残留扫描、锁文件校验
- [x] 阶段 3: 在当前工作树重新安装并运行类型检查、lint、测试与构建 —— 验证方式：项目原生验证入口
- [ ] 阶段 4: 提交并推送，所有干净工作树快进到迁移提交并重新安装 —— 验证方式：各分支 HEAD、状态和 `node_modules` 核验

## 验收

- 仓库不再依赖 `package-lock.json`，使用固定 pnpm 版本和 `pnpm-lock.yaml`
- CI 使用 pnpm 缓存、冻结锁文件安装和 `pnpm exec`
- 当前代码、活跃文档和运行脚本无 npm 包管理器入口残留
- 定向门禁、构建和完整回归结果明确记录
- 远端迁移提交存在，所有可安全同步的工作树包含该提交并完成依赖重装
