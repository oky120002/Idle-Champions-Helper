# 国内托管与访问优化

- 作用：记录国内访问优化的备选方案与决策。

## 当前部署

- 技术栈：`Vite + React + TypeScript`
- 部署：`GitHub Pages + GitHub Actions`，默认域名
- 国内访问优化优先级：`Cloudflare Pages` / CDN 加速 高于国内云托管

## 优化触发条件

当出现以下信号时评估优化：

- 中国大陆打开速度明显拖慢使用
- 静态 JSON 数据加载成为瓶颈
- 高频反馈“打不开”或“加载太慢”

## 优化路径

1. 先试 `Cloudflare Pages` 或 CDN 加速。
2. 若确认大量中国大陆访问且体验必须稳定，再评估国内托管。决策前确认：是否愿意处理备案、是否需要自定义域名、是否真的比 `Cloudflare Pages` / CDN 加速更划算。

国内云厂商方案保留为后续备选，当前不进入实现范围。
