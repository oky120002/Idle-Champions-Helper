## 角色定位

**蔚是 support（提供善良榜样给出言不逊增强），不是自己的 carry。** 善良榜样 `filter_targets: geneutral`，`geneutral` 是伦理中立阵营标签（Neutral / Lawful Neutral / Chaotic Neutral）。蔚自身 `Neutral Good`（伦理 good）**无 geneutral 标签**（raw `hero.original.tags` 确认），不可能是自己善良榜样的目标。carry 须另选 geneutral 英雄（如 Jaheira、Deekin、Nrakk 等 47 个 geneutral 英雄之一）。

游戏内善良榜样「叠层系数」显示的是**能力对 geneutral 目标的输出倍率**，非蔚自身 DPS。

## 原话（用户描述）

## 机制分析

蔚同时用 4 个通用机制（非蔚专属）：

- `formation-count-mult-stack`：善良榜样 per_hero mult，count=good|acqinc|cteam，target=geneutral。
- `dynamic-stack-multiply`：出言不逊 stacksMultiply，层数来自 `highest_available_area×10`（数值表达式，归一化降 unsupported，由 `manualStackCount=1930` 提供假设）。
- `bonus-scale-linkage`：出言不逊挂在善良榜样上（`bonusScaleOfSignal` 依赖检查，不卷入数值）。
- `buff-upgrade-modifier`：道德规范（specialization +20%）/ 时髦披肩（equipment +157.8%）修饰善良榜样。

count 限定 vs target 限定：蔚 ed=1644 同时携带 `stack_func_data:{tag:"good|acqinc|cteam"}`（count）与 `filter_targets:[{by_tags:geneutral}]`（target），二者语义不同，归一化须分别读入 `formationCountQualifier` 与 `targetQualifier`，不可混用。

`geneutral` 标签语义：伦理中立阵营（Neutral / Lawful Neutral / Chaotic Neutral），全库 47 个英雄有此标签、且全是伦理中立；`Neutral Good` 英雄（含蔚）均无此标签。

## 推导与偏差

- 善良榜样：`4^7 = 16384`（7 名 good 英雄，per_hero 计数；对 geneutral 目标生效）。
- 出言不逊：`1.0033^1930 ≈ 577`（0.33%/层 是游戏取整显示，实际略低；游戏叠层加成 57,639% = 576.39 倍，吻合）。
- pool 倍率（**研究 flat-factor 分解**，非代码产出）：`16384 × 577 × 1.2 × 2.578 ≈ 2.92e7`，对照游戏善良榜样「叠层系数」`2.92e09%` = 2.92e7 倍，偏差 < 1%。此分解把修饰作独立乘 ×(1+修饰/100)，是研究对游戏机制的解读；代码实际 pool 组合见下条。
- 不对照绝对 DPS：`baseDamage` 未校准，绝对 DPS 须 BUD 校准联动（绝对值校准属后续工作）。
- buff_upgrade 修饰折算（**代码实际**）：外部源 buff_upgrade（loot 装备 / feat / 专长，非 stacksMultiply）按基础 `value`（per-stack 百分比，善良榜样=300）× 修饰值/100 折算进 addPercent，**非**聚合倍率（4^N）——用聚合倍率会使 +100% 修饰被算成 ×4^N（灾难高估）。ability 源静态 buff_upgrade（ranked 进阶 + 同 ability 源 effect_keys 静态修饰，如劝人向善 +200%）的贡袋已烘进 effect_string snapshot value，不派生为独立 addPercent。
- pool 对照现状：蔚 damage:hero poolMultiplier ≈ 1.66e7（multFactor 16384×576=9.44e6 + 时髦披肩 rarity1 addPercent 75），对照游戏叠层系数 2.92e7 为 0.57×（欠估 1.75×）。欠估来源：(a) 道德规范专长 +20% 未建模（specialization 信号未入 built）；(b) 时髦披肩取 rarity1 +25% 而非最高 rarity +157.8%（loot rarity 选择 bug）；(c) pool addPercent 线性累加 vs 游戏修饰独立乘的近似差。逐项 `multiplierChecks`（per-signal，16384/576）仍是有效自动化校准；pool 级对照待 (a)(b) 补全后落地。
