# specs/product/ —— 产品定义

产品价值、形态、技术模型与风险。描述「产品是什么」（不是「要做什么」——那是 `changes/`）。

## 文档

- [`value-and-positioning.md`](./value-and-positioning.md)：项目价值、定位、目标用户
- [`product-shape.md`](./product-shape.md)：产品形态、数据底座、成功口径
- [`technical-models.md`](./technical-models.md)：技术路线原则、核心数据模型
- [`risks.md`](./risks.md)：产品风险与应对
- [`future-features.md`](./future-features.md)：未来特性清单（需求库）——明确当前不做、将来可能做的特性

## 规则

- 描述产品现状与定义，不写里程碑/变更叙事
- 演进方向的具体计划 → `changes/`
- 未来可能做但未排期的特性/需求 → `future-features.md`（需求库，区别于 `TODO.md` 的工程优化与 `changes/` 的具体计划）
- 技术决策的「为什么」→ `decisions/`
