# 方案存档：页面结构与交互

## 页面结构

1. 外层统一使用页面工作台：顶部是标题、状态 badge、复制当前链接；桌面端无大页头。
2. 右区内容头优先承载状态提示，再进入范围说明和方案列表。
3. 主体保持「范围说明 → 方案列表 → 卡片内编辑/删除/恢复」顺序；当前无左栏，走隐藏左栏模式。

不需要复杂分页；优先把空态、列表态、编辑态跑通。

## 与其他模块的衔接

- 来自阵型编辑：`layoutId`、`placements`、`scenarioRef`、当前数据版本 `dataVersion`。

## 核心交互

MVP 支持：查看方案列表、创建方案、编辑方案名与备注、删除方案、从阵型草稿生成方案、识别并提示失效引用方案。

最小流程：阵型编辑页形成草稿 → 点击「保存为方案」→ 填写名称/备注/场景标签 → 保留当前 `scenarioRef` → 写入本地存储 → 方案存档页可见并可再次打开。
