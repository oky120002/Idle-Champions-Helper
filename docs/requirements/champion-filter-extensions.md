# 英雄筛选扩展

**优先级**：待评

## 是什么

英雄筛选模块的 MVP 补全与扩展，按以下顺序推进：

1. **Patron 过滤** + 结果解释（命中 Patron 维度可过滤并显示）
2. **目标模式过滤**（模式维度缩小候选池）
3. **结构化规则数据集合**（筛选结果和不可用原因消费同一规则来源）
4. **过滤标签扩展**（阵营 / 种族 / 职业 / 活动年限更可读）
5. **个人画像接入**（owned / unowned、已解锁 / 未解锁标记）
6. **细场景规则**（Variant 规则、冒险 / 变体上下文联动）
7. **可解释模板推荐**（只做可解释模板推荐，不做黑盒打分）

## 为何暂缓

当前筛选模块覆盖基础维度（seat、关键词、tag 派生组、特殊机制），主体功能可用。上述扩展是渐进增强，按价值排序逐步推进。
