# 方案存档跨模块集成扩展

**优先级**：个人画像集成待评

## 是什么

方案存档接入筛选条件快照与个人画像，增强方案表达力：

1. ✅ **筛选条件快照**（2026-08-07 落地）：保存当前筛选条件、进入方案详情时反向恢复候选池。英雄列表页「带着筛选去摆阵型」入口 → 阵型页消费 URL 筛选 → 保存方案写入 `filterSnapshot` → 恢复方案按快照还原候选池
2. ✅ **常用筛选组合**（2026-08-24 落地）：英雄列表页独立保存、命名、恢复和删除 11 维筛选条件，不与阵型方案混成同一对象
3. **个人画像集成**：标记方案里哪些英雄未拥有、根据个人画像提示替代位（依赖个人画像结构稳定）

## 为何暂缓

方案数据结构需承接筛选快照和个人画像扩展，不破坏现有恢复逻辑。个人画像集成依赖画像结构稳定后再做。
